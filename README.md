# Néon 89

Portfolio interactif de Victor Therache, développeur full-stack, en français et en anglais.

Une ville vue de dessus générée en direct dans un canvas, un menu façon cassette VHS et des chapitres :
Présentation, Projets, Éducation, Expérience, Contact.

- Une seule page, sans dépendance ni étape de build : `index.html`.
- Le contenu (FR et EN) se modifie dans l'objet `CONTENT` en haut du script.
- Musique : « Mystery » par JustinBeats. Bruitages synthétisés avec la Web Audio API.

Pour le tester en local : ouvrir `index.html` dans un navigateur, ou servir le dossier (`python -m http.server`).
